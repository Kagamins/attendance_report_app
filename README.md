# تقارير الحضور والانصراف (Flet)

تطبيق سطح مكتب يقرأ «تقرير حركة موظف (مختصر)» بصيغة PDF من نظام البصمة، ويحسب كل المؤشرات **بعدد الموظفين (أفراد)** لا بعدد البصمات، ويُنشئ التقارير.

## التثبيت (Windows)
1. ثبّت Python 3.11 أو 3.12 من python.org (فعّل خيار *Add Python to PATH*).
2. انقر مرتين على `setup_windows.bat` (مرة واحدة فقط؛ يحتاج إنترنت).
3. لتشغيل التطبيق: انقر مرتين على `run_windows.bat`.

على Mac أو Linux: `bash run_mac_linux.sh` (يثبّت في أول مرة ثم يشغّل).

## الاستخدام
| الصفحة | ما تفعله |
|---|---|
| **البيانات** | اختيار ملف PDF، وتقرير سابق اختياري للمقارنة (الموظفون الجدد ومن لم يعودوا موجودين)، وتحديد الفترة والتواريخ المستبعدة وأيام العمل |
| **لوحة المؤشرات** | البطاقات الرئيسية والمسار الأسبوعي ومقارنة الأسبوع الأحدث بما قبله وأيام الأسبوع. **اضغط على أي بطاقة لعرض أسماء الموظفين** |
| **الموظفون** | جدول كل الموظفين مع 20 مجموعة جاهزة (تأخروا دون إذن، غابوا دون عذر، منقطعون، منضبطون…) وبحث وترتيب. اضغط على أي موظف لسجله اليومي وتقريره الفردي PDF. تصدير القائمة Excel أو PDF، أو إضافتها كملحق في التقرير |
| **التقارير** | التقرير الكامل PDF مع اختيار أقسامه وملاحقه (وخيار إخفاء الأسماء)، والإنفوجرافيك PNG + PDF، وملف Excel التفاعلي (10 أوراق بالمعادلات)، وجدول جميع الموظفين |
| **الإعدادات** | اسم المدرسة وسطر الجهة والتوقيعات، وقواعد الاحتساب: حد التأخير (07:55)، الانصراف المبكر (13:20)، النصاب (370 د من 07:10)، نافذة T2 (121–181 د)، حد التكرار (6) |

القراءة الأولى لملف من 400 صفحة تستغرق نحو 30–60 ثانية، ثم يُحفظ الناتج مؤقتاً فيفتح الملف نفسه فوراً بعد ذلك.
الإعدادات والذاكرة المؤقتة في المجلد `~/.attendance_reports`. التقارير تُحفظ في `المستندات/تقارير الحضور` (قابل للتغيير).

## قواعد الاحتساب
- **التأخير**: الحضور عند حد التأخير أو بعده. **دون إذن**: لا يوجد إذن حضور أو تخفيف مسجل في النظام.
- **الانصراف المبكر**: الخروج قبل حد الانصراف. **دون إذن**: لا يوجد إذن انصراف أو تخفيف أو إعفاء جزئي مسجل في النظام.
- **الغياب دون عذر**: حالة «غياب» أو «منقطع عن العمل» في النظام، أو يوم بلا أي بصمة وبلا إجازة.
- **الدوام الكامل**: الانصراف بعد max(بداية النصاب، T1) + النصاب.
- **المسار**: مؤشر الدوام الكامل في الأسبوع الأحدث مقارنة بمعدل الأسابيع السابقة (±10 نقاط).
- كل رقم في الأسابيع = عدد موظفين مختلفين، والإجمالي يعدّ الشخص مرة واحدة.

## ملاحظات
- الأسماء تُعرض كما وردت في ملف البصمة (بعضها مختصر في النظام نفسه).
- ملف Excel التفاعلي يحسب معادلاته عند فتحه في Excel (قد يستغرق ثوانٍ عند الفتح الأول).
- لإنشاء ملف تنفيذي واحد (exe): `flet pack main.py --name "تقارير الحضور"`. يجب تشغيل `python -m playwright install chromium` على الجهاز المستخدم أيضاً.

## نسخة Android (ملف APK)
التطبيق نفسه يعمل على الهاتف: نفس الصفحات والتصفية وعرض الأسماء، مع شريط تنقل سفلي. الفروق على الهاتف:
- ملفات PDF تُنشأ بمحرك مدمج (بدون متصفح)، والإنفوجرافيك PDF فقط (بدون PNG).
- التقارير تُحفظ في مجلد **التنزيلات/AttendanceReports**، وتُفتح من تطبيق «الملفات».
- القراءة الأولى لملف من 400 صفحة على الهاتف أبطأ (دقيقتان إلى أربع تقريباً)، ثم يفتح فوراً.

### بناء ملف APK دون تثبيت أي شيء (عبر GitHub مجاناً)
1. أنشئ حساباً على github.com ثم **New repository** (يمكن جعله Private).
2. اختر **uploading an existing file** واسحب **كل محتويات** هذا المجلد (بما فيها مجلد `.github`) ثم **Commit changes**.
   - إن لم يظهر مجلد `.github` بعد الرفع: **Add file ← Create new file**، واكتب المسار `.github/workflows/build-apk.yml` والصق محتوى الملف نفسه.
3. افتح تبويب **Actions** ← **Build Android APK** ← **Run workflow**. يستغرق البناء 15–25 دقيقة.
4. من صفحة التشغيل المكتمل نزّل **attendance-reports-apk** من قسم Artifacts، وفك الضغط لتحصل على ملف `.apk`.
5. انقل الملف إلى الهاتف وافتحه، واسمح بـ«تثبيت التطبيقات من مصادر غير معروفة» عند السؤال.

### أو البناء على جهازك
`pip install "flet[all]==0.28.3"` ثم من داخل هذا المجلد: `flet build apk` (يُنزّل Flutter وAndroid SDK تلقائياً، نحو 5–10 جيجابايت في أول مرة). الملف الناتج في `build/apk`.

---
**English quick start:** install Python 3.11/3.12, run `setup_windows.bat` once, then `run_windows.bat`. The code is in `main.py` (UI, flet 0.28.3) and `core/` (parser, analysis, people stats, PDF report, infographic, Excel workbook).

**Android:** push this folder to a GitHub repo and run the *Build Android APK* workflow (Actions tab); download the APK from the run's artifacts. Or run `flet build apk` locally with flet 0.28.3. On phones, PDFs are produced by the built-in reportlab renderer (`core/pdf_lite.py`, with `core/arabic.py` for Arabic shaping) and pdfplumber/pdfminer are bundled in `vendor/` (MIT) so no compiled PDF libraries are needed.
